# GUI 사용 중 조정하기

이 문서는 GUI를 기본값으로 사용해 본 뒤, 속도나 안정성 때문에 조정이 필요할 때
참고하는 문서입니다.

기본 원칙:

- 먼저 기본 실행으로 확인한다.
- 문제가 있을 때만 값을 바꾼다.
- 속도를 올릴 때는 반드시 `Decode` 결과까지 확인한다.

## Slide 속도 조정

송신 PC의 `Slide` 탭에서 조정합니다.

- `Page(ms)`: 한 QR 이미지를 화면에 보여 주는 시간
- `Black(ms)`: 다음 QR 이미지로 넘어가기 전 검은 화면 시간
- `Loop`: 전체 QR 이미지 세트를 반복하는 횟수

처음 권장값:

- `Page(ms)`: `100`
- `Black(ms)`: `50`
- `Loop`: `1`

실패가 많으면 `Page(ms)`를 늘립니다. 화면 깜빡임이나 캡처 누락이 보이면
`Black(ms)`를 조금 늘립니다.

## Capture 미리보기 조정

수신 PC의 `Capture` 탭에서 조정합니다.

- `Preview`: 캡처 화면 미리보기 켜기/끄기
- `Preview FPS`: GUI 미리보기 갱신 빈도

`Preview`와 `Preview FPS`는 캡처 실행 중에도 바꿀 수 있습니다. 저장되는 QR
이미지 자체가 아니라 GUI 화면 갱신량에 영향을 줍니다.

GUI가 느리게 느껴지면 아래 순서로 낮춥니다.

1. `Preview FPS`를 낮춘다.
2. 그래도 느리면 `Preview`를 끈다.
3. 캡처 완료 후 `Decode` 결과를 확인한다.

## Decode 결과 기준으로 판단

전송 성공 여부는 화면상 저장 개수만으로 판단하지 않습니다. 복원 출력 폴더에
원본 파일이 생겼는지 확인합니다.

복원이 되지 않으면 슬라이드 속도를 낮추거나 캡처 장치 위치를 조정합니다. 문제가
반복되면 화면 초점, 밝기, 해상도, 캡처 장치 상태를 먼저 확인합니다.

## 언제 조정하나

아래 상황이면 조정을 검토합니다.

- `Decode` 중 메모리 부족이 나는 경우
- `Capture`가 오래 돌면서 느려지거나 불안정한 경우
- 대량 QR PNG를 한 번에 처리하는 경우
- 복원이 반복해서 실패하는 경우
- GUI 미리보기 때문에 조작이 느려지는 경우
